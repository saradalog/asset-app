# 資産管理アプリ セットアップ手順

画面（index.html）を GitHub Pages に置き、データは Google スプレッドシート＋Apps Script に保存します。
URL未設定の状態で開くとデモデータが表示されるので、先に見た目を確認できます。

## ファイル
| ファイル | 置き場所 |
|---|---|
| `Code.gs` | スプレッドシートの Apps Script |
| `index.html` / `manifest.json` / `icon-180.png` / `icon-512.png` | GitHub リポジトリ（Pages） |

## 1. スプレッドシートと Apps Script
1. Google スプレッドシートを新規作成（名前は例「資産管理」）
2. メニュー「拡張機能 → Apps Script」を開き、`Code.gs` の中身を全部貼り付けて保存
3. 関数の選択で `setup` を選び「実行」→ 権限を承認
   - シート「保有」「配当受取」「資産推移」「設定」が作られ、毎日7時・16時の自動更新が登録されます
   - 実行ログ（またはシート上のダイアログ）に **トークン** が出ます。メモしておきます
4. 「デプロイ → 新しいデプロイ → 種類：ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（トークンで保護しています）
   - デプロイ後の **ウェブアプリURL**（…/exec）をコピー

> Code.gs を書き換えたときは「デプロイを管理 → 編集 → バージョン：新しいバージョン」で更新します（URLは変わりません）。

## 2. GitHub Pages
1. 新しいリポジトリ（例 `asset-app`）を作り、index.html・manifest.json・アイコン2つをアップロード
2. Settings → Pages → Branch: `main` / `(root)` で保存
3. 数分後 `https://<ユーザー名>.github.io/asset-app/` で開けます

## 3. スマホで使う
1. iPhone は Safari、Android は Chrome で上のURLを開く
2. 共有メニュー →「ホーム画面に追加」
3. アプリの「設定」タブで ウェブアプリURL と トークン を入れて「保存して接続」

## 入力のしかた
| 種別 | コード | 数量 | 取得単価 | 価格 |
|---|---|---|---|---|
| 日本株 | 7203 | 株数 | 円 | 自動 |
| 米国株 | AAPL / VOO | 株数 | ドル | 自動 |
| 中国株 | 0700 | 株数 | 香港ドル | 自動 |
| 投資信託 | 任意 | 口数 | 1万口あたり円 | **手動価格**に基準価額（1万口あたり） |
| 暗号資産 | BTC / ETH | 数量 | 円 | 自動 |
| 金 | 任意 | グラム | 円/g | 国際金価格から自動計算（税抜） |
| 現金 | 任意 | 金額 | 不要 | 不要 |

- 外貨建ては「取得時の為替」を入れると、為替差も含めた損益になります（空欄なら現在レートで計算）
- 「年間配当/株」を入れると予想配当・利回り・FIREの配当カバー率に反映されます
- 価格が自動で取れない銘柄（新しい英字入りコードなど）は「手動価格」を入れてください

## 注意
- 価格は GOOGLEFINANCE（最大20分程度の遅延）。金（XAUUSD）が取れない日は前回値のまま、または手動価格で対応
- 予想配当の税引後は概算（特定/一般 20.315%、NISA 非課税、米国株・中国株は現地課税10%）
- 資産推移は自動更新のたびにその日の行を上書きします

## 日本株の株数・取得単価は「保有詳細」が元（2026-11-14〜）
- 日本株の株数・取得単価は、四季報ビューアの「四季報ビューア 監視銘柄」シートの「保有詳細」タブから毎日7時・16時に自動で合わせます（`syncFromHoldDetail_()`）。日本株の株数は四季報ビューアで入力してください。このアプリで直しても次の同期で戻ります。
- 同じ銘柄が口座別に複数行あるときは1行にまとめます（口座は「合算」）。保有詳細が口座の合計だからです。
- 「売却履歴」タブにある銘柄は日本株の行から消します。保有詳細にも売却履歴にも無い日本株の行は触りません。
- 米国株・中国株・投信・暗号資産・金・現金はこれまでどおりこのアプリで入力します。
- すぐ同期したいときはスプレッドシートのメニュー「資産管理 → 保有詳細から日本株を同期」。
- 初めて動かすときは「監視銘柄」シートを読む権限の承認が出ます（同じGoogleアカウントのシートなので承認するだけ）。
