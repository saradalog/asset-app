# asset_check — 全資産の定期点検

株・債券・現金・金・コモディティ・REIT・暗号資産・オルタナティブ（上場の代わり）の約30資産について、毎月つぎを計算します。

- 成績：年率（ドル建て・円建て、名目・実質）、直近1・3・5・10・20年の円建て年率
- リスク：ぶれ（標準偏差）、最大下落、最悪の12か月、高値を取り戻すまでの最長期間、10年保有で実質マイナスだった割合
- 分散効果：米国株との相関（全期間・直近3年）、米国株が月5%以上下げた月の平均騰落
- 割高度：米国株CAPE、株と債券の期待リターンの差（1/CAPE − 実質金利）、金の実質価格（中央値比）
- 判定：資産の役割（値上がり・安定・備え・利回り・高リスク・現金）ごとに「良好 / 要注意 / 見直し」の目安

## 動き方

1. GitHub Actions「Asset Check Monthly」が毎月3日 09:23 JST に `run.py` を実行し、`results/` を更新してコミットする（手動実行も可）
2. Claude の定期タスクが結果を読み、ダッシュボード「S&P500・オルカンの優位性は続くか？ 検証」に反映し、判定が変わった資産だけ知らせる。毎年1月は年次レポートを出す

## 出力

- `results/latest.json` … 最新の結果
- `results/history/YYYY-MM.json` … 毎月の保存（判定の変化を比べる）
- `results/report.md` … 人が読む要約

## ローカルで試す

```
pip install requests pandas numpy yfinance lxml
python asset_check/run.py
```

## 注意

- 判定は過去データにもとづく目安で、売買の指示ではない。過去の検証では、割高度で売り買いしても長期の成績はほとんど改善しなかった。判定は配分・取り崩し率・期待値の見直しに使う。
- データは無料の公開データ（Yahoo Finance・FRED・GitHub datasets）だけ。J-Quantsのデータは使わない。
